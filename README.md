# DSA media

Public images for the Greasy Fork description of **The DSA: Daliban Surveillance Apparatus** userscript.

Every username, message, mention, link, embed, nuke and viewer count in these images is placeholder data. They were recorded from the unmodified userscript running on a stand-in chat page, not from real Destiny.gg chat.

Each release's images live in their own folder (for example `v0.46.47/`), so links already used in a description keep working when newer images are added.

| File | Shows |
| --- | --- |
| `latest-release.gif` | The release at a glance: live chat, a watched user arriving, a new mention, then each toolbar panel |
| `main-menu.gif` | The DSA menu, Citizen Movements and the Ministry of Public Viewing graph |
| `mentions.gif` | A new mention arriving and the Intercepts panel |
| `nukes.gif` | The Ministry of Chat Harmony: recent nukes, link controls and the phrase archive |
| `links.gif` | Latest Link Dispatches with image and video previews |
| `nuke-active.gif` | A live nuke: the alarm row in chat, the pulsing nuke icon and the Ministry panel |
